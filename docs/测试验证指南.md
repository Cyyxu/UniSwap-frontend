### 测试 8: XSS 攻击防护
**步骤：**
1. 登录成功后
2. 在控制台执行以下代码：

```javascript
// 尝试从 localStorage 读取 Token
console.log('localStorage token:', localStorage.getItem('token'))

// 尝试从 Cookie 读取 Refresh Token
console.log('document.cookie:', document.cookie)

// 尝试访问内存中的 Token（应该失败）

```

**预期结果：**
- ✅ `localStorage.getItem('token')` 返回 `null`
- ✅ `document.cookie` 中**看不到** `refreshToken`（因为是 HttpOnly）
- ✅ `window._accessToken` 返回 `undefined`（内存变量不暴露到全局）

## 自动化测试脚本

### 使用 Playwright 测试

```javascript
// tests/auth.spec.ts
import { test, expect } from '@playwright/test';

test.describe('认证功能测试', () => {
  test('登录并验证 Token 存储', async ({ page, context }) => {
    await page.goto('http://localhost:5173/login');
    
    // 登录
    await page.fill('input[placeholder="请输入账号"]', 'test');
    await page.fill('input[placeholder="请输入密码"]', '12345678');
    await page.click('button[type="submit"]');
    
    // 等待跳转
    await page.waitForURL('http://localhost:5173/');
    
    // 验证 localStorage 中没有 token
    const localStorageToken = await page.evaluate(() => localStorage.getItem('token'));
    expect(localStorageToken).toBeNull();
    
    // 验证 Cookie 中有 refreshToken
    const cookies = await context.cookies();
    const refreshTokenCookie = cookies.find(c => c.name === 'refreshToken');
    expect(refreshTokenCookie).toBeDefined();
    expect(refreshTokenCookie?.httpOnly).toBe(true);
  });
  
  test('刷新页面保持登录', async ({ page }) => {
    // 先登录
    await page.goto('http://localhost:5173/login');
    await page.fill('input[placeholder="请输入账号"]', 'test');
    await page.fill('input[placeholder="请输入密码"]', '12345678');
    await page.click('button[type="submit"]');
    await page.waitForURL('http://localhost:5173/');
    
    // 刷新页面
    await page.reload();
    
    // 验证仍然在首页（未跳转登录）
    expect(page.url()).toBe('http://localhost:5173/');
    
    // 验证用户信息显示
    const userInfo = await page.locator('.user-info').isVisible();
    expect(userInfo).toBe(true);
  });
  
  test('登出清除认证信息', async ({ page, context }) => {
    // 先登录
    await page.goto('http://localhost:5173/login');
    await page.fill('input[placeholder="请输入账号"]', 'test');
    await page.fill('input[placeholder="请输入密码"]', '12345678');
    await page.click('button[type="submit"]');
    await page.waitForURL('http://localhost:5173/');
    
    // 登出
    await page.click('text=退出登录');
    
    // 验证跳转到登录页
    await page.waitForURL('http://localhost:5173/login');
    
    // 验证 Cookie 被清除
    const cookies = await context.cookies();
    const refreshTokenCookie = cookies.find(c => c.name === 'refreshToken');
    expect(refreshTokenCookie).toBeUndefined();
  });
});
```

## 常见问题排查

### 问题 1: 刷新页面后跳转登录
**可能原因：**
- 后端未实现 `/api/user/refresh` 接口
- Cookie 未正确设置（缺少 HttpOnly 或 Path）
- CORS 配置未允许 credentials

**排查步骤：**
1. 检查 Network 中是否有 `/api/user/refresh` 请求
2. 检查请求是否带上 Cookie
3. 检查响应是否返回新的 Access Token

---

### 问题 2: Token 刷新死循环
**可能原因：**
- 刷新接口本身返回 401
- 刷新接口路径判断错误

**排查步骤：**
1. 检查 `request.ts` 中的路径判断：
```typescript
if (originalRequest.url?.includes('/auth/refresh') || originalRequest.url?.includes('/user/refresh'))
```
2. 确保刷新接口路径匹配

---

### 问题 3: Cookie 无法设置
**可能原因：**
- 后端未设置 CORS 允许 credentials
- Cookie 的 Domain 或 Path 不匹配

**排查步骤：**
1. 检查后端 CORS 配置：
```java
.allowCredentials(true)
```
2. 检查 Cookie 的 Path 设置为 `/`
