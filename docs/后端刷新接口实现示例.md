# 后端刷新接口实现示例

## Java Spring Boot 实现

### 1. 登录接口改造

```java
@PostMapping("/login")
public Result<LoginResponse> login(@RequestBody LoginRequest request, HttpServletResponse response) {
    // 验证用户名密码
    User user = userService.login(request.getUserAccount(), request.getUserPassword());
    
    // 生成 Access Token (短期有效，15-30分钟)
    String accessToken = jwtUtil.generateAccessToken(user.getId());
    
    // 生成 Refresh Token (长期有效，7-30天)
    String refreshToken = jwtUtil.generateRefreshToken(user.getId());
    
    // 将 Refresh Token 存入 HttpOnly Cookie
    Cookie cookie = new Cookie("refreshToken", refreshToken);
    cookie.setHttpOnly(true);  // 关键：防止 JS 读取
    cookie.setSecure(true);    // 生产环境必须：仅 HTTPS 传输
    cookie.setPath("/");
    cookie.setMaxAge(7 * 24 * 60 * 60); // 7 天
    cookie.setSameSite("Strict"); // 防止 CSRF
    response.addCookie(cookie);
    
    // 返回 Access Token 和用户信息
    LoginResponse loginResponse = new LoginResponse();
    loginResponse.setAccessToken(accessToken);
    loginResponse.setUser(user);
    
    return Result.success(loginResponse);
}
```

### 2. 刷新接口实现

```java
@PostMapping("/refresh")
public Result<RefreshResponse> refresh(HttpServletRequest request) {
    // 从 Cookie 中获取 Refresh Token
    String refreshToken = null;
    Cookie[] cookies = request.getCookies();
    if (cookies != null) {
        for (Cookie cookie : cookies) {
            if ("refreshToken".equals(cookie.getName())) {
                refreshToken = cookie.getValue();
                break;
            }
        }
    }
    
    // 验证 Refresh Token
    if (refreshToken == null || !jwtUtil.validateRefreshToken(refreshToken)) {
        throw new BusinessException(ErrorCode.UNAUTHORIZED, "Refresh Token 无效或已过期");
    }
    
    // 从 Refresh Token 中提取用户 ID
    Long userId = jwtUtil.getUserIdFromRefreshToken(refreshToken);
    
    // 生成新的 Access Token
    String newAccessToken = jwtUtil.generateAccessToken(userId);
    
    // 返回新的 Access Token
    RefreshResponse response = new RefreshResponse();
    response.setAccessToken(newAccessToken);
    
    return Result.success(response);
}
```

### 3. 登出接口改造

```java
@PostMapping("/logout")
public Result<Boolean> logout(HttpServletResponse response) {
    // 清除 Refresh Token Cookie
    Cookie cookie = new Cookie("refreshToken", null);
    cookie.setMaxAge(0);
    cookie.setPath("/");
    cookie.setHttpOnly(true);
    response.addCookie(cookie);
    
    return Result.success(true);
}
```

### 4. JWT 工具类示例

```java
@Component
public class JwtUtil {
    
    @Value("${jwt.secret}")
    private String secret;
    
    @Value("${jwt.access-token-expiration:1800000}") // 30分钟
    private Long accessTokenExpiration;
    
    @Value("${jwt.refresh-token-expiration:604800000}") // 7天
    private Long refreshTokenExpiration;
    
    /**
     * 生成 Access Token
     */
    public String generateAccessToken(Long userId) {
        Date now = new Date();
        Date expiryDate = new Date(now.getTime() + accessTokenExpiration);
        
        return Jwts.builder()
                .setSubject(String.valueOf(userId))
                .setIssuedAt(now)
                .setExpiration(expiryDate)
                .claim("type", "access")
                .signWith(SignatureAlgorithm.HS512, secret)
                .compact();
    }
    
    /**
     * 生成 Refresh Token
     */
    public String generateRefreshToken(Long userId) {
        Date now = new Date();
        Date expiryDate = new Date(now.getTime() + refreshTokenExpiration);
        
        return Jwts.builder()
                .setSubject(String.valueOf(userId))
                .setIssuedAt(now)
                .setExpiration(expiryDate)
                .claim("type", "refresh")
                .signWith(SignatureAlgorithm.HS512, secret)
                .compact();
    }
    
    /**
     * 验证 Access Token
     */
    public boolean validateAccessToken(String token) {
        try {
            Claims claims = Jwts.parser()
                    .setSigningKey(secret)
                    .parseClaimsJws(token)
                    .getBody();
            return "access".equals(claims.get("type"));
        } catch (Exception e) {
            return false;
        }
    }
    
    /**
     * 验证 Refresh Token
     */
    public boolean validateRefreshToken(String token) {
        try {
            Claims claims = Jwts.parser()
                    .setSigningKey(secret)
                    .parseClaimsJws(token)
                    .getBody();
            return "refresh".equals(claims.get("type"));
        } catch (Exception e) {
            return false;
        }
    }
    
    /**
     * 从 Token 中获取用户 ID
     */
    public Long getUserIdFromToken(String token) {
        Claims claims = Jwts.parser()
                .setSigningKey(secret)
                .parseClaimsJws(token)
                .getBody();
        return Long.parseLong(claims.getSubject());
    }
    
    /**
     * 从 Refresh Token 中获取用户 ID
     */
    public Long getUserIdFromRefreshToken(String token) {
        if (!validateRefreshToken(token)) {
            throw new BusinessException(ErrorCode.UNAUTHORIZED, "无效的 Refresh Token");
        }
        return getUserIdFromToken(token);
    }
}
```

## 安全建议

### 1. Token 过期时间设置
- **Access Token**: 15-30 分钟（短期）
- **Refresh Token**: 7-30 天（长期）
- 根据业务安全要求调整

### 2. Cookie 安全属性
- `HttpOnly`: 必须设置，防止 XSS 攻击
- `Secure`: 生产环境必须设置，仅 HTTPS 传输
- `SameSite`: 设置为 `Strict` 或 `Lax`，防止 CSRF 攻击
- `Path`: 设置为 `/`，确保所有接口都能访问

### 3. Refresh Token 存储
可选方案：
- **方案 1**: 仅存 Cookie（本方案采用）
- **方案 2**: Cookie + Redis（更安全，可实现单点登录）
  - Cookie 存 Token ID
  - Redis 存 Token 内容和用户信息
  - 可实现强制登出、单设备登录等功能

### 4. 防止 Token 重放攻击
- 每次刷新时生成新的 Refresh Token（Token Rotation）
- 旧的 Refresh Token 立即失效
- 检测到重放攻击时，撤销所有 Token

### 5. IP 和 User-Agent 绑定（可选）
```java
public String generateRefreshToken(Long userId, HttpServletRequest request) {
    String ip = request.getRemoteAddr();
    String userAgent = request.getHeader("User-Agent");
    
    return Jwts.builder()
            .setSubject(String.valueOf(userId))
            .claim("ip", ip)
            .claim("userAgent", userAgent)
            .claim("type", "refresh")
            // ...
            .compact();
}

public boolean validateRefreshToken(String token, HttpServletRequest request) {
    Claims claims = Jwts.parser()
            .setSigningKey(secret)
            .parseClaimsJws(token)
            .getBody();
    
    String tokenIp = claims.get("ip", String.class);
    String tokenUserAgent = claims.get("userAgent", String.class);
    String currentIp = request.getRemoteAddr();
    String currentUserAgent = request.getHeader("User-Agent");
    
    return tokenIp.equals(currentIp) && tokenUserAgent.equals(currentUserAgent);
}
```

## 常见问题

### Q1: 为什么不把 Refresh Token 也放内存？
A: Refresh Token 需要在刷新页面后仍然有效，所以必须持久化。HttpOnly Cookie 是最安全的持久化方式。

### Q2: 如何实现"记住我"功能？
A: 调整 Refresh Token 的过期时间即可。例如：
- 不勾选"记住我"：7 天
- 勾选"记住我"：30 天

### Q3: 如何实现强制登出？
A: 使用 Redis 存储 Refresh Token：
```java
// 登录时
redisTemplate.opsForValue().set("refresh_token:" + userId, refreshToken, 7, TimeUnit.DAYS);

// 刷新时
String storedToken = redisTemplate.opsForValue().get("refresh_token:" + userId);
if (!refreshToken.equals(storedToken)) {
    throw new BusinessException(ErrorCode.UNAUTHORIZED, "Token 已失效");
}

// 强制登出
redisTemplate.delete("refresh_token:" + userId);
```

### Q4: 如何实现单设备登录？
A: 每次登录时覆盖 Redis 中的 Refresh Token，旧设备的 Token 自动失效。

### Q5: 前端如何知道 Token 即将过期？
A: 可以在 Access Token 中添加过期时间字段，前端提前 1-2 分钟主动刷新。
