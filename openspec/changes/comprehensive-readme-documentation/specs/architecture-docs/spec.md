## ADDED Requirements

### Requirement: Tech Stack Documentation
The README SHALL list all major technologies used including React, TypeScript, Ant Design, Vite, and state management libraries.

#### Scenario: Tech stack is clear
- **WHEN** a developer reviews the tech stack section
- **THEN** they understand all major technologies and libraries used in the project

### Requirement: Project Structure Visualization
The README SHALL include a visual representation of the project folder structure with descriptions of each major directory.

#### Scenario: Developer navigates codebase
- **WHEN** a developer needs to find specific code
- **THEN** they can use the structure diagram to locate the appropriate directory

### Requirement: Architecture Overview
The README SHALL provide a high-level architecture diagram showing the relationship between frontend, backend, and external services.

#### Scenario: System architecture understanding
- **WHEN** a developer needs to understand system architecture
- **THEN** they can view a diagram showing component relationships and data flow

### Requirement: Module Organization
The README SHALL explain how the codebase is organized into modules (pages, components, api, store, utils).

#### Scenario: Module purpose is clear
- **WHEN** a developer wants to add new functionality
- **THEN** they know which module/folder to place their code in

### Requirement: State Management Documentation
The README SHALL explain the state management approach using Zustand and when to use global vs local state.

#### Scenario: State management guidance
- **WHEN** a developer needs to manage application state
- **THEN** they understand how to use Zustand stores appropriately
