## Why

The project currently lacks a comprehensive README documentation at the root level. While there is extensive documentation in the `docs/` folder focused on API changes and backend integration, there is no central, user-facing README that provides an overview of the entire project, its features, setup instructions, and development guidelines. This makes it difficult for new developers to onboard and understand the project structure quickly.

## What Changes

- Create a comprehensive `README.md` at the project root
- Include project overview, features, tech stack, and architecture
- Add detailed setup and installation instructions
- Document development workflow and best practices
- Provide API documentation references
- Include deployment guidelines
- Add contribution guidelines and project structure explanation
- Link to existing detailed documentation in `docs/` folder

## Capabilities

### New Capabilities
- `project-overview`: Complete project introduction including purpose, features, and target users
- `setup-guide`: Step-by-step installation and configuration instructions
- `development-guide`: Development workflow, coding standards, and best practices
- `architecture-docs`: System architecture, tech stack, and project structure documentation
- `deployment-guide`: Production deployment instructions and environment configuration
- `api-reference`: Quick API reference and links to detailed API documentation
