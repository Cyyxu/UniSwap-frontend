## ADDED Requirements

### Requirement: Project Title and Description
The README SHALL include a clear project title and concise description that explains the purpose of UniSwap as a campus second-hand trading platform.

#### Scenario: Reader understands project purpose
- **WHEN** a developer reads the project title and description
- **THEN** they understand it is a campus trading platform with community and AI features

### Requirement: Feature Highlights
The README SHALL list all major features of the platform including e-commerce, community, messaging, AI chat, and admin management.

#### Scenario: Feature list is comprehensive
- **WHEN** a developer reviews the feature list
- **THEN** they can identify all major functional modules (商品交易, 社区互动, 消息系统, AI助手, 后台管理)

### Requirement: Target Audience
The README SHALL clearly identify the target users as campus students and the use case as second-hand item trading.

#### Scenario: Target audience is clear
- **WHEN** a reader reviews the project overview
- **THEN** they understand the platform is designed for campus students

### Requirement: Project Status and Badges
The README SHALL include status badges for version, build status, and license information.

#### Scenario: Status is visible
- **WHEN** a developer views the README
- **THEN** they can see current version, build status, and license at a glance
